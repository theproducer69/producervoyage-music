# Background Music Files

This folder contains audio files for Voyage projects.

## Usage with voyage.io

To link these audio files in your Voyage projects, use the raw GitHub URL format:

```
https://raw.githubusercontent.com/theproducer69/producervoyage-music/main/audio/[filename].mp3
```

### Example:
If you have a file named `background-music.mp3`, the URL would be:
```
https://raw.githubusercontent.com/theproducer69/producervoyage-music/main/audio/background-music.mp3
```

### In HTML/JavaScript:
```html
<audio autoplay loop>
  <source src="https://raw.githubusercontent.com/theproducer69/producervoyage-music/main/audio/your-file.mp3" type="audio/mpeg">
</audio>
```

## Adding Files

Place your audio files directly in this folder and update this README with file descriptions.
